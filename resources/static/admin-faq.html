Essential configuration and security guidelines for SmartHR administrative custodians

How can I modify Geofence office perimeter coordinates?
Geofence markers can be updated in the **Admin Security Settings** panel. Ensure you enter correct latitude and longitude coordinates along with a boundary radius (recommended: 100 meters) before hitting Apply Geofence Changes.
Where do I audit database log edits?
Open the **Admin Analytics Portal** via the bottom navigation menu. The portal offers audit tables, recruitment funnel tracking, department division metrics, and a raw CSV exporter button to archive log histories.
How do I view AI Retention and Flight Risk metrics?
Navigate to the **Admin Analytics Portal**. The AI predictive engine automatically scans attendance logs, leave patterns, and engagement metrics to generate a Flight Risk Score for every employee. High-risk employees are flagged in the **AI Insights & Action Items** section.
What is the standard procedure for onboarding a new department?
First, set up the new department credentials under the Directory control settings. Then configure matching leave parameters in the LMS module so that new hires automatically receive target leave allocations.
How can I trigger outgoing Webhook payloads to external systems?
Configure target system URLs inside the **Integration Center**. Ensure you specify the secure secret verification key to protect system payload transmissions.
