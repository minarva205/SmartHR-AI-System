SmartHR AI – Human Resource Management System

SmartHR AI is a web-based Human Resource Management System designed to make HR activities easier, faster and more organized. It brings employee management, attendance, payroll, recruitment and other HR operations together on one platform with AI-powered assistance.

#Key Features

## 1. Navigation & Hero Section
**Company Logo**– Represents the identity of the platform.
**Home / Dashboard** – Provides easy access to the main page.
**About Us** – Explains the purpose of the platform.
**Login / Signup** – Separate login options for Admin and Employees.
**AI Smart Search** – Helps users find HR information and documents.
**Language Toggle** – Allows users to change the display language.

###2. Core HR Management
**Employee Directory** – Maintains employee details and profiles.
**Attendance Tracker** – Records and monitors employee attendance.
**Leave Management** – Handles leave applications and approvals.
**Payroll Management** – Manages salary details and payslips.
**Recruitment (ATS)** – Organizes job applications and hiring processes.
**Performance Reviews** – Tracks employee performance and progress.
**Training & LMS** – Manages employee learning and training.
**Task Management** – Helps assign and track employee tasks.

### 3. AI-Powered Features

**AI HR Chatbot** – Answers common HR-related questions.
**Predictive Employee Churn** – Identifies possible employee attrition risks.
**AI Resume Parser** – Extracts important details from resumes.
**Sentiment Analysis** – Analyzes employee feedback and opinions.
**Automated Scheduling** – Helps schedule interviews and meetings.
**Smart Notifications** – Sends important alerts and reminders.
**AI Expense Claims** – Helps extract details from expense bills.

### 4. Employee Self-Service & Engagement
 **My Profile** – Allows employees to view and update their information.
 **Announcements** – Shares important company updates.
 **Employee Feedback** – Collects suggestions and opinions.
 **Birthday & Anniversary** – Displays employee celebrations.
 **Employee Leaderboard** – Highlights employee achievements.
 **Holiday Calendar** – Shows company holidays.
 **Internal Feed** – Provides a space for sharing workplace updates.

### 5. Support & Security

 **Help Desk** – Allows employees to raise support requests.
 **Policy Documents** – Provides access to company rules and policies.
 **Security Settings** – Manages account and security preferences.
**Integration Center** – Supports connections with external services.
 **Mobile App Support** – Provides mobile-friendly access.
 **Analytics Dashboard** – Displays HR reports and statistics.
**Privacy Policy** – Explains how user information is handled.
 **Contact Support** – Provides contact information for assistance.
 **FAQ Section** – Answers frequently asked questions.
 **Testimonials** – Displays user experiences and reviews. 
## Technologies Used
- **Frontend:** HTML, CSS, Tailwind CSS
- **Backend:** Java, Spring Boot
- **Database:** MySQL
## Project Objective
To simplify HR operations, reduce manual work, improve employee management and make workplace activities more efficient through intelligent technology.
